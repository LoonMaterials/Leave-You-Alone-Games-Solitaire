Support

Leave Me Alone Games is designed to work offline, without accounts, advertisements, or subscriptions.

Quick fixes

  • Use New Game, New Deal, or New Match inside a game if a saved round is no longer wanted.
  • Use Reset App Data on the main menu to clear saved preferences and game state on this device.
  • For pass-and-play card games, give the device to the named player and let that player tap the button that reveals their hand.
  • The Android and iOS versions contain the games locally and should remain playable without an internet connection.

Report a problem

Open a request in the project’s public issue tracker. Include the game name, device model, operating-system version, and the steps that led to the problem. Do not include passwords or other private information.
